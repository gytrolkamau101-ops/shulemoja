# ShuleMoja
Kenya school OS — React + Vite + Supabase.

## Run
cp .env.example .env   # set VITE_SUPABASE_*
npm i && npm run dev

## Deploy
Netlify: build `npm run build`, publish `dist`. SQL: run `migrations/` in order (or already-applied schools skip).

## Money rule
Platform STK (subscriptions) only. School fees stay at the school — never on BigData accounts.
